✅ CountVectorizer:
    ✨ installation: pip install scikit-learn
    ✨ from sklearn.feature_extraction.text import CountVectorizer

➡️ Uses - Converts text into Numerical Vector  
    Sentence1 - I watch movies.
    Sentence2 - I watch Action movies.

    CountVectorizer create a matrix likes below -

    Words           S1          S2
    I               1           1
    watch           1           1
    movies          1           1
    Action          0           1
