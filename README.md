# Movie-Recommendation-App
An AI-powered Movie Recommendation App developed using Python, Machine Learning, Streamlit, and the TMDb API. It recommends similar movies and displays posters, ratings, genres, and movie details through an interactive interface.
# 🎬 Movie Recommendation App

## ✨ Features

- 🎥 Content-Based Recommendation
- 🖼️ TMDB Poster Fetching
- ⚡ Fast Recommendation
